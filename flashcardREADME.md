# Flashcard Quiz App

A responsive Flashcard Quiz Application built using HTML, CSS and JavaScript.

## Features
- Add new flashcards
- Edit flashcards
- Delete flashcards
- Show and hide answers
- Next and Previous navigation
- Search flashcards
- Category filters
- Track study progress
- Responsive design
- Save flashcards using Local Storage

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Description
This application helps users create and study their own flashcards. Each user can manage their flashcards, and the data is saved in their own browser using Local Storage.
